# Tic Tac Toe in C

A simple console-based Tic Tac Toe game written in C.

## Features
- Two Player Gameplay
- Colored Console Output
- Winner Detection
- Draw Detection
- Position Guide for Players

## Files
- main.c : Main game logic
- tic.c : Helper functions
- main.h : Function declarations and macros

## Compilation

gcc main.c tic.c -o tictactoe

## Run

./tictactoe
